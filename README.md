# Sweden Momentum Radar

Interaktiv high-risk momentumscanner för svenska aktier, med fokus på snabb kursrörelse, relativ volym, små-/tillväxtbolag och tydliga riskflaggor.

## Funktioner

- Topplista över snabb-rörliga svenska aktier
- Filter för risk, relativ volym och börsvärde
- Momentumscore
- Förklaringar för aktier som stiger mer än 10 % på en dag
- Katalysatorklassificering och säkerhetsnivå
- Responsiv, fristående webbapp

## Hosting

Appen är byggd som en statisk webbapp och kan hostas direkt via GitHub Pages från `main`-branchen och repository root.

## Viktigt

Detta är ett research- och screeningverktyg, inte investeringsrådgivning. Hög-risk momentumaktier kan röra sig kraftigt i båda riktningar och låg likviditet kan förstora procentuella rörelser.
